# Component Groups

Component groups in Lunar help organize components by their functionality and purpose. Each component belongs to a specific group that defines its category and intended use.

## Core System Components

### `LUNAR`
Core components essential for the Lunar system's operation.
- System initialization
- Core workflows
- Basic operations

### `UTILS`
General-purpose utility components.
- Common operations
- Helper functions
- Basic data manipulation

## Data Processing
